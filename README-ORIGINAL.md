# Proyecto-Revisor-de-contratos-simples
Escogí el proyecto Revisor de contratos simples porque permite aplicar la inteligencia artificial a una tarea cotidiana del derecho. La herramienta ayudaría a identificar cláusulas importantes, obligaciones, fechas y posibles riesgos dentro de un contrato, facilitando su revisión y ahorrando tiempo al abogado, sin reemplazar su criterio profesional
